# ثلاث الذكي

مساعد قراءة لمكتبة ثلاث. يفتحه الزائر من رمز QR على جواله، بلا حساب ولا تحميل تطبيق، فيسأله عمّا يريد أن يقرأ ويقترح عليه كتبًا متوفرة في المكتبة مع سبب كل اقتراح. ومعه لوحة إدارة للموظفين: الكتب والمخزون والمؤلفون والفعاليات والإحصاءات.

*Thalath Smart: an Arabic reading assistant for the Thalath bookshop. Visitors open it from a QR code and get suggestions from the books in stock; staff manage the catalog from an admin page. Install steps in English: [INSTALL.md](INSTALL.md).*

**الإصدار الحالي: 0.9.8 beta** · ما الذي تغيّر: [CHANGELOG.md](CHANGELOG.md)

## التحميل

النسخة الجاهزة في صفحة الإصدارات: **[Releases](https://github.com/eyesmystery/library-keeper/releases/latest)**. فيها ثلاثة ملفات:

| تريد | الملف |
|---|---|
| تثبيتًا جديدًا على ويندوز | الملف الذي ينتهي بـ `windows.zip` |
| تثبيتًا جديدًا على ماك | الملف الذي ينتهي بـ `mac.zip` |
| **تحديث** تطبيق مثبّت عندك (ويندوز أو ماك) | الملف الذي يبدأ بـ `ThalathSmart-update` |

ملف التثبيت الجديد نحو 500 ميغابايت، وفيه التطبيق كاملًا: الكود، وكتالوج المكتبة (أكثر من 5,300 كتاب)، وأغلفة الكتب، وملفات التشغيل، وتعليمات بالعربية.

المستودع خاص، فالتحميل يحتاج تسجيل الدخول إلى GitHub بحساب له صلاحية عليه.

## التشغيل في خمس خطوات

**ويندوز**

1. ثبّت Python 3 من [python.org/downloads](https://www.python.org/downloads/)، وفعّل عند التثبيت الخيار **Add python.exe to PATH**.
2. فك الملف المضغوط، وانقل المجلد الذي يخرج منه (`ThalathSmart-…`) إلى مكان ثابت مثل «المستندات».
3. انقر مرتين على `start_library.bat`. أول مرة يجهّز نفسه في نحو دقيقة ويحتاج إنترنت. إذا سأل Windows عن السماح لـ Python بالشبكة فاسمح على **الشبكات الخاصة**.
4. تفتح صفحة الإدارة `http://127.0.0.1:8802/admin`. أنشئ حساب المدير (أول مرة فقط).
5. الإعدادات ← رمز QR: امسح الرمز بالجوال، والجوال على نفس الواي فاي.

**ماك**

1. تأكد من Python 3: افتح Terminal واكتب `python3 --version`. إن لم يكن موجودًا فثبّته من [python.org/downloads](https://www.python.org/downloads/).
2. فك الملف المضغوط، وانقل المجلد الذي يخرج منه (`ThalathSmart-…`) إلى مكان ثابت مثل «المستندات».
3. انقر مرتين على `start_library.command`. إذا منعه macOS أول مرة: انقر عليه بالزر الأيمن ثم «فتح».
4. تفتح صفحة الإدارة `http://127.0.0.1:8802/admin`. أنشئ حساب المدير (أول مرة فقط).
5. الإعدادات ← رمز QR: امسح الرمز بالجوال، والجوال على نفس الواي فاي.

التفاصيل وحلول المشاكل في [INSTALL.md](INSTALL.md).

## التحديث بدون فقد تعديلاتكم

لا تثبّت الحزمة الكاملة فوق تطبيق يعمل: هي تستبدل كل شيء. استعمل **ملف التحديث** (نحو 85 ميغابايت):

1. أغلق نافذة السيرفر.
2. فك ملف التحديث، وانقل المجلد الناتج إلى **داخل** مجلد التطبيق، بجانب `start_library`.
3. انقر مرتين على `install_update.bat` (ويندوز) أو `install_update.command` (ماك).
4. بعد علامة ✓ شغّل التطبيق كالعادة.

| يبقى كما هو | يتغيّر |
|---|---|
| حسابات الموظفين وكلمات المرور، الإعدادات ونموذج الذكاء الاصطناعي | ملفات التطبيق (الصفحات والسيرفر) |
| الفعاليات وصورها، أقسام المكتبة | بيانات الكتب التي لم تعدّلوها: النبذات، الأنواع، المؤلفون، الجوائز، آراء القراء |
| الكميات والأسعار ومواقع الرفوف، وما استوردتموه من «رواء» | الأغلفة التي لم ترفعوا بديلًا لها |
| بلاغات الزوار، ملاحظات الموظفين، الإحصاءات | |
| أي حقل في كتاب عدّلتموه بأنفسكم، وأي غلاف رفعتموه | |

إذا عدّلتم حقلًا وجاء التحديث بقيمة مختلفة له، تبقى قيمتكم، ويُكتب ذلك في تقرير داخل مجلد `updates` ترسلونه إلى إبراهيم. قبل أي تغيير تُحفظ نسخة من القاعدة والملفات القديمة في `backups/before_update_…`. التفاصيل في [INSTALL.md](INSTALL.md).

## نموذج الذكاء الاصطناعي

بدون نموذج يعمل التطبيق ويرشّح بالكلمات، لكن الردود أبسط. لاختيار نموذج: صفحة الإدارة ← الإعدادات ← الذكاء الاصطناعي. الخيارات:

| الخيار | ما يلزمه |
|---|---|
| **Ollama** (المضبوط في الحزمة) | تطبيق Ollama من [ollama.com/download](https://ollama.com/download) مع تسجيل الدخول فيه. النماذج السحابية (`:cloud`) لا تحتاج تنزيلًا كبيرًا. |
| **Ollama Cloud** | مفتاح من [ollama.com/settings/keys](https://ollama.com/settings/keys)، بلا تطبيق Ollama على الجهاز. |
| **مفتاح API** | مفتاح من Claude أو ChatGPT أو Gemini أو OpenRouter، أو أي مزوّد متوافق مع OpenAI. |
| **ChatGPT عبر Codex** | برنامج Codex CLI مثبّت ومسجّل دخوله بحساب ChatGPT، بلا مفتاح. |

المفاتيح تُكتب في صفحة الإعدادات فقط، وتُحفظ خارج مجلد التطبيق في `~/.library_keeper/keys.json`. لا تضع أي مفتاح في ملفات المشروع.

البحث بالمعنى (مثل «كتاب عن الغربة») يحتاج تطبيق Ollama والنموذج `bge-m3`. بدونه يبقى البحث بالكلمات.

## ما في هذا المستودع

| المجلد | محتواه |
|---|---|
| `backend/` | السيرفر (Python و Flask و SQLite) |
| `frontend/` | صفحة الزائر |
| `admin/` | لوحة الإدارة |
| `scripts/` | النسخ الاحتياطي والاسترجاع، بناء الحزم، وأدوات استيراد البيانات |
| `tests/` | الاختبارات (`tests/run_all.py`) |
| `docs/` | وثائق التطوير، وتعليمات الاستخدام والملف التعريفي (PDF) |

قاعدة الكتالوج `data/library.db` والأغلفة ليست داخل git. تأتي مع ملفات الإصدار. من ينسخ المستودع بـ `git clone` يأخذ مجلد `data` من حزمة الإصدار (الخطوات في INSTALL.md).

## الفروع والإصدارات

- `main`: النسخة الحالية «ثلاث الذكي».
- `mvp` والوسم `v1.0-mvp`: النسخة الأولى (27 سبتمبر 2026) وكان اسمها «أمين المكتبة — الإصدار ١٫٠»: 500 كتاب تجريبي ولوحة إدارة أساسية. محفوظة للرجوع إليها. الترقيم الحالي (0.9.x beta) بدأ بعدها، فالرقم 0.9.8 أحدث من «١٫٠» القديم.

## الخصوصية

الحزمة لا تحتوي حسابات موظفين ولا كلمات مرور ولا سجل عمليات ولا محادثات زوار ولا مفاتيح. النسخ الاحتياطية تُحفظ على جهازك في مجلد `backups/`.
